Why Coinnect exists

Moving money between currencies should be transparent, neutral, and free. Most "comparison" sites either run hidden affiliate fees, push you to one provider, or simply lie about rates. We built Coinnect to do the opposite: surface the real cost of every route — including the spread the provider doesn't show you — and let you decide.

We don't custody funds. We don't process payments. We don't collect personal data. Coinnect is a read-only routing engine: you ask "USD to MXN $500", we tell you the cheapest 5 routes ranked by total cost, and you take it from there with the provider of your choice.

How it works

  • CCXT for crypto exchanges (Kraken, Binance, Coinbase, Bitso, and more)
  • Wise static fiat rates
  • Yellow Card Africa rails (NGN, KES, GHS, UGX)
  • Western Union + MoneyGram baseline rates
  • x402 micropayment support for agentic usage
  • Background refresh every 3 minutes, history persisted in SQLite

Built for AI agents

Coinnect was designed from day one to be agent-friendly. The full API is documented at /docs, the llms.txt at /llms.txt declares discoverability, and there's a native MCP server (python -m coinnect.mcp_server) so any Claude/GPT/local LLM can quote and explain rates without scraping.

Tools available via MCP: coinnect_quote, coinnect_corridors, coinnect_explain_route.

Who we are

Coinnect is a project by KOA Labs, a small technology studio in Mexico City. We build tools, protocols, and products that we think should exist and that don't.

Other things we build: lacartelera.app (comedy directory MX), sociales.lat (social dance LATAM), lemonadeprice.com (global cost-of-living index), ceiba.to (community protocol), and several more.

Independence and funding

Coinnect is self-funded by KOA Labs. No venture capital, no investor pressure, no roadmap dictated by anyone but us. We chose this on purpose: a money routing engine financed by a money exchange would be a conflict of interest.

If Coinnect ever charges, it will be for premium features (higher rate limits, real-time SLAs, white-label embeds) — never for the public API or the free comparison.

Open code, open data

The core comparison engine is open source. The historical rate data is exportable. The MCP server is published on PyPI. The methodology is documented at /docs.

If you find a bug or want a new exchange added, open an issue on github.com/koalabs/coinnect or write us at hello@coinnect.bot.
